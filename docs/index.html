What it does

All your devices in one place

Mice, keyboards, headsets and controllers, each with its battery level, whether it's charging, and how long it has left.

In the tray

A battery icon per device next to the clock, and a small panel with all of them when you click it.

Alerts before it dies

A Windows notification when a device runs low, set once for everything or per device, plus charging and fully charged alerts.

History

A 24-hour and 7-day chart for each device, its drain rate, and when it was last charged.

Knows when it's off

A device switched off while its receiver stays plugged in shows as asleep or off, not as an old reading.

Light and private

Uses about 1% of a CPU core and runs entirely on your PC. Nothing is collected or sent anywhere.

Questions

Windows says "Windows protected your PC". Is it safe?

That warning appears for any app that isn't code-signed, which costs money every year and this project is free. Select More info, then Run anyway. Every release is built automatically by GitHub from the public source code, and each one comes with a SHA-256 checksum so you can check the file is exactly what was built.

Does it need an account or send my data anywhere?

No. Everything runs on your PC. It only goes online to check GitHub for updates. Device reports open in your browser, and nothing is sent unless you submit them yourself.

My device isn't listed.

Open Add device: supported devices are marked, and for others the 30-second scan can often find the battery value. If that doesn't work, send a device report from the app so support can be added.

Does it update itself?

Yes. New versions download in the background and install when you restart the app.
